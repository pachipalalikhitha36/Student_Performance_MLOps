# Student Performance MLOps

An end-to-end Machine Learning and MLOps project for predicting student performance.

## Project Objective

The system predicts whether a student is likely to Pass or Fail based on academic features.

## Input Features

- Study Hours
- Attendance
- Previous Marks
- Assignment Score
- Internal Marks

## Machine Learning Algorithm

Random Forest Classifier

## MLOps Tools

- Git
- GitHub
- DVC
- MLflow
- Apache Airflow
- GitHub Actions
- Docker
- Cloud Deployment

## Project Pipeline

Student Data
→ Preprocessing
→ Model Training
→ Model Evaluation
→ MLflow
→ DVC
→ Airflow
→ GitHub Actions
→ Docker
→ Cloud
